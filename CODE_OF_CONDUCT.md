# Code of Conduct

All Zen-In-Tech repositories and project spaces follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment and personal attacks are not accepted.

## Reporting

Report unacceptable behavior to the organization owners. Clients: ask in your project portal for a private channel. Every report is reviewed and kept confidential.
