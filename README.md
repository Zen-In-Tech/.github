# .github

Organization profile and default community health files for Zen-In-Tech.

These files apply to every repository in the organization that does not have its own version.

| Path | Purpose |
|---|---|
| `profile/README.md` | Public organization profile |
| `.github/ISSUE_TEMPLATE/` | Issue forms: bug, feature, change request, question |
| `.github/PULL_REQUEST_TEMPLATE.md` | Pull request template |
| `CONTRIBUTING.md` | Branching, commits and pull requests |
| `SECURITY.md` | How to report a vulnerability |
| `CODE_OF_CONDUCT.md` | Code of conduct |
| `SUPPORT.md` | Where to get help |
