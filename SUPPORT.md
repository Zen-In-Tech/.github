# Support

## Clients

Use your project portal: the private `<client>-portal` repository you were invited to.

| You need to | Where |
|---|---|
| Report a bug | Issues → New issue → **Bug report** |
| Ask for a new feature | Issues → New issue → **Feature request** |
| Change agreed scope or delivered work | Issues → New issue → **Change request** |
| Ask a question | Issues → New issue → **Question**, or Discussions |
| See releases and release notes | **Releases** in the portal |

One topic per issue, please. Never post passwords, keys or personal data in issues or comments. Ask us for a secure way to share them.
